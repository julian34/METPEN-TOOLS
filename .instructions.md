# metpen-ai-lab Workspace Instructions

**Context**: This is a VS Code Dev Container project for teaching research methods with responsible AI assistance in Indonesian educational settings.

## Quick Reference

- **Language**: Indonesian for student-facing content; English for code and technical identifiers
- **Architecture**: Dev Container + Python 3.11 + Jupyter notebooks
- **Learning Path**: 7 notebooks (orientation → data loading → cleaning → EDA → descriptive stats → correlation/regression → case study)
- **Data**: Synthetic student performance data (clearly labeled as synthetic)

## Key Principles (Read Before Any Changes)

1. **No hallucination**: Only create what's explicitly listed in [metpen-ai-lab.md](metpen-ai-lab.md)
2. **Synthetic data must be labeled**: Never present synthetic data as real
3. **Relative paths only**: No personal paths like `C:\...` or `/Users/...`
4. **Beginner-friendly**: Clear explanations over complex code
5. **No optional tools**: No extra frameworks unless explicitly listed
6. **Use placeholders for uncertainty**: Add TODO instead of guessing
7. **Reproducibility first**: Working lab > feature completeness
8. **Dependencies in Dockerfile**: Never use `postCreateCommand`

## Common Tasks

### Modifying Notebooks

- Check [AGENTS.md](AGENTS.md) § "Adding or Modifying a Notebook"
- Keep structure consistent with existing notebooks
- Use relative paths
- Include Markdown explanations before complex code
- Mark synthetic data clearly

### Working with Data

- Synthetic data: [data/synthetic/](data/synthetic/)
- Generator script: [scripts/generate_synthetic_student_data.py](scripts/generate_synthetic_student_data.py)
- All synthetic datasets need disclaimer: _"This dataset is synthetically generated for learning purposes"_

### Testing

```bash
pytest tests/
```

### Dev Container Updates

- Edit [.devcontainer/Dockerfile](.devcontainer/Dockerfile) for dependencies
- Rebuild container after changes (don't use postCreateCommand)

## File Structure

```
notebooks/          # 7-notebook learning progression
data/
  ├── raw/         # Real data (with documented sources)
  ├── synthetic/   # Practice data (labeled as synthetic)
  └── processed/   # Cleaned outputs
prompts/           # AI prompt templates for students
templates/         # Student templates (AI log, interpretation)
scripts/           # Automation (data generation, tests)
```

## Responsible AI Teaching

This project teaches students to use AI responsibly:

- AI helps explain, choose methods, interpret results
- AI must NOT fabricate data or replace critical thinking
- Students must verify, document, and reflect on AI usage

See [docs/02-ai-usage-policy.md](docs/02-ai-usage-policy.md) for full policy.
